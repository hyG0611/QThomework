# Qt 考勤管理系统 — 开发文档

---

## 1. 需求分析

### 1.1 功能需求

| 模块 | 功能 | 说明 |
|------|------|------|
| 人脸识别考勤 | 1:N 识别 | 摄像头采集人脸，提取特征并与数据库中所有学生特征比对，识别成功后写入考勤记录 |
| 学生信息管理 | 增删改查 | 管理学生姓名、学号、性别、民族、身份证号、人脸特征、班级 |
| 考勤信息管理 | 查找 | 按学号、日期等条件查询考勤记录 |
| 考勤统计 | 柱状图 | 统计指定日期出勤人数与未出勤人数 |

### 1.2 非功能需求

- **跨平台**：Windows、Linux、macOS 均可编译运行
- **实时性**：人脸识别响应时间 < 2 秒
- **可维护性**：分层架构，数据库、业务、界面解耦
- **安全性**：身份证号等敏感信息建议加密存储；人脸特征以二进制形式存储

## 2. 技术选型

| 组件 | 选型 | 理由 |
|------|------|------|
| GUI 框架 | Qt Widgets | 跨平台、信号槽机制成熟、图表模块完善 |
| 数据库 | MySQL | 稳定、易用、与 Qt 集成方便 |
| 人脸识别 | SeetaFace6 | 开源、离线运行、支持人脸检测/关键点/识别 |
| 图像采集 | OpenCV + Qt Multimedia | OpenCV 采集摄像头，Qt 显示视频帧 |
| 图表 | Qt Charts | 官方模块，与 Qt 深度集成 |
| 构建工具 | CMake | 跨平台、现代 C++ 项目标准 |

## 6. 人脸识别流程

1. **图像采集**：OpenCV 从摄像头读取一帧
2. **人脸检测**：SeetaFace `FaceDetector` 定位人脸位置
3. **关键点检测**：SeetaFace `FaceLandmarker` 获取 5 个关键点
4. **特征提取**：SeetaFace `FaceRecognizer` 提取 256/512 维特征向量
5. **1:N 比对**：与 `students.face_feature` 中所有特征计算余弦相似度
6. **阈值判断**：相似度 > 阈值（如 0.65）则识别成功，写入考勤记录

## 8. 开发步骤建议

### 第一阶段：环境搭建（1-2 天）

1. 安装 Qt、MySQL、OpenCV
2. 下载并编译 SeetaFace6 或获取预编译库
3. 测试 Qt 连接 MySQL
4. 测试 SeetaFace6 人脸检测与识别

### 第二阶段：基础框架（2-3 天）

1. 创建 CMake 项目
2. 实现 `DatabaseManager` 与 DAO 层
3. 设计并实现 `Student`、`AttendanceRecord` 模型
4. 完成数据库初始化脚本

### 第三阶段：人脸模块（3-5 天）

1. 封装 `FaceEngine`
2. 实现人脸特征提取与比对
3. 实现摄像头采集与实时显示
4. 将人脸特征写入数据库（注册/编辑学生时）

### 第四阶段：界面开发（3-5 天）

1. 主窗口与导航
2. 学生管理界面
3. 人脸识别考勤界面
4. 考勤查询与统计界面

### 第五阶段：测试与优化（2-3 天）

1. 单元测试 DAO 层
2. 人脸识别准确率测试
3. 跨平台编译验证
4. 性能优化（特征库索引、批量查询）

## 9. 关键注意点

1. **人脸特征存储**：MySQL 中建议使用 `BLOB` 或 `LONGBLOB`，C++ 侧使用 `QByteArray` 或 `std::vector<float>`。
2. **并发安全**：数据库连接单例化，QSqlDatabase 在子线程中需独立连接。
3. **摄像头权限**：在 Windows/macOS 上注意申请摄像头权限。
4. **SeetaFace 模型路径**：使用相对路径或配置文件，避免硬编码。
5. **跨平台路径**：使用 `QDir`、`QStandardPaths` 处理路径分隔符。
