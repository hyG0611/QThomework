# 数据搜集指南

为了顺利开发和测试本考勤管理系统，需要提前准备以下数据。

---

## 1. 学生基础信息数据

### 1.1 需要搜集的字段

| 字段 | 示例 | 说明 |
|------|------|------|
| 学生姓名 | 张三 | 真实姓名或测试用假名 |
| 学号 | 2022010001 | 唯一标识，建议统一编码规则 |
| 性别 | 男 / 女 | 可映射为 1/2 |
| 民族 | 汉族 | 可下拉选择 |
| 身份证件号 | 11010120000101XXXX | 测试数据可虚构，注意脱敏 |
| 班级 | 计算机 2201 | 与班级表或班级字段对应 |

### 1.2 数据来源建议

- **模拟生成**：使用在线假数据生成器或 Python Faker 库生成测试数据
- **学校教务系统导出**（需授权）：如真实项目，可向教务部门申请脱敏后的学生名单
- **手动录入**：适合小规模测试（10-50 人）

### 1.3 示例 CSV 格式

```csv
student_no,name,gender,ethnicity,id_card,class_name
2022010001,张三,男,汉族,DEMO-ID-001,计算机2201
2022010002,李四,女,汉族,DEMO-ID-002,计算机2201
2022010003,王五,男,回族,DEMO-ID-003,计算机2202
```

## 2. 人脸图像数据

### 2.1 采集要求

| 项目 | 建议 |
|------|------|
| 图像格式 | JPG / PNG |
| 分辨率 | 建议 ≥ 640×480，人脸区域清晰 |
| 光照 | 均匀自然光，避免过曝或逆光 |
| 姿态 | 正面或接近正面，避免大角度侧脸 |
| 表情 | 自然表情，避免夸张表情 |
| 遮挡 | 尽量不戴眼镜、口罩、帽子（或保证测试场景一致） |
| 背景 | 简洁背景，减少干扰 |
| 命名规则 | `学号_姓名.jpg`，如 `2022010001_张三.jpg` |

### 2.2 每个人需要几张照片

- **注册照片**：1-3 张正面清晰照片
- **测试照片**：不同光线、角度的照片若干，用于测试识别准确率

### 2.3 数据来源建议

1. **自行拍摄**：用摄像头或手机拍摄同学/同事的正面照
2. **公开人脸数据集**（仅用于算法学习）：
   - LFW (Labeled Faces in the Wild)
   - CASIA-WebFace
   - VGGFace2
3. **网络图片**：注意版权与隐私，仅用于本地测试

> ⚠️ **隐私提示**：真实学生照片属于敏感个人信息，必须获得授权并妥善保管，不得上传到公共仓库或网络。

## 3. 考勤测试数据

### 3.1 模拟考勤记录

在开发初期没有人脸识别模块时，可以手动插入一些考勤记录用于测试查询和统计功能。

```sql
INSERT INTO attendance_records (student_no, attendance_time, attendance_type, check_mode)
VALUES
('2022010001', '2026-07-08 08:30:00', 0, 0),
('2022010002', '2026-07-08 08:31:20', 0, 0),
('2022010003', '2026-07-08 08:35:10', 1, 0);
```

### 3.2 数据量建议

- 开发测试：10-50 人，每人几条记录
- 性能测试：100-1000 人，考察人脸识别 1:N 速度

```csv
class_name,department,grade
计算机2201,计算机学院,2022
计算机2202,计算机学院,2022
软件工程2201,软件学院,2022
```

---

## 5. 推荐的数据准备流程

1. 设计好数据格式（CSV 模板）
2. 收集/生成 10-50 条学生基础信息
3. 为每个学生拍摄或准备 1-3 张人脸照片
4. 使用脚本批量导入学生信息到 MySQL
5. 批量提取人脸特征并更新到 `students.face_feature`
6. 手动插入若干考勤记录用于测试查询/统计
